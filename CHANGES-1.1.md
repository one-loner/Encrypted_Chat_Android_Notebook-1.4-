# Записная книжка / Notebook 1.1.0 — отчёт об изменениях

Дата: 15 октября 2026. Минимальная версия Android — API 24.
Application ID `com.loner.encryptedchat`, имена прежнего файла Vault/Keystore alias
и пользовательские настройки сохранены. versionCode повышен с 1 до 2.

## Реализовано

1. Общий переключатель расположения сообщений: собственные справа, остальные
   слева. При выключении сохраняется прежний вид. Настройка хранится между запусками.
2. Несколько серверов с отдельными HTTPS-адресами, учётными данными,
   включённостью и проверкой подключения. Отключение сохраняет данные.
3. Объединение одинаковых названий комнат и ключевых фраз в одну вкладку,
   независимо от локального имени ключа. У разных ключей остаются разные вкладки.
4. Параллельная отправка на серверы, зашифрованная долговременная очередь,
   частичные результаты, повторы и восстановление после перезапуска/переподключения.
5. Дедупликация по аутентифицированному конверту, с сохранением всех источников.
   Разные сообщения с одинаковым текстом не склеиваются.
6. SOCKS5 отдельно на сервер: параметры, проверка, необязательная авторизация,
   DNS назначения на стороне прокси, HTTPS внутри туннеля, сообщения об ошибках.
7. Заметница с отдельными паролем, файлом и Keystore-ключом. На стартовом экране
   одно поле. Основной пароль открывает чаты, пароль заметницы — только заметки.
   Есть создание, смена пароля, CRUD заметок, автосохранение и блокировка.
8. Имя «Записная книжка» / «Notebook», обычная, адаптивная и монохромная иконки.
9. Сохранены ключи/QR, свайпы, текст/вложения, RU/EN, зашифрованный экспорт/импорт
   и исходное шифрование, совместимое с сервером без его модификации.

## Принятые решения

- **Миграция schema 1 → 2:** одиночная учётная запись превращается в сервер,
  история и ключи сохраняются, добавляются ID вкладок, состав серверов, источники
  сообщений и outbox. Старый пароль/Keystore остаются действительными.
  Миграция записывается атомарно; старые зашифрованные копии поддерживаются.
- **Идентификатор сообщения:** SHA-256 декодированных IV и ciphertext с GCM-тегом.
  При рассылке/повторах используется ровно тот же конверт. Случайный clientMessageId
  также включается внутрь зашифрованного payload. Текст и время не являются ключом
  дедупликации. Источники хранят serverId, ID, sender, createdAt и fileId.
- **Резервирование:** отдельные рабочие потоки серверов, отдельные сеансы каждой
  пары «сервер + вкладка». Подтверждённые адресаты не повторяются. Перед повторным
  POST после неопределённого результата проверяется наличие конверта в истории.
  Повторы работают при открытой основной области; блокировка закрывает ключи.
  Подтверждение доставки монотонно: поздняя ошибка не отменяет успех. Удаление
  локального чата отменяет его ожидающие сетевые задачи.
- **Ограничение существующего PHP API:** сервер не поддерживает idempotency key.
  При гонке таймаута и повторного POST на сервере могут появиться одинаковые записи;
  обновлённый клиент показывает их один раз. Строгая гарантия одной серверной записи
  потребовала бы изменения серверного API.
- **Смена адреса/логина:** новая серверная идентичность, прежняя отключается.
  Старые ожидающие сообщения не пересылаются автоматически другому получателю.
  При добавлении сервера существующие чаты получают его в состав; состав редактируется.
- **SOCKS5:** собственный SocketFactory для RFC 1928/1929, без глобального
  Authenticator и без отключения проверки TLS. Пустой прокси означает прямое соединение.
  Пароли прокси находятся внутри зашифрованного Vault и его зашифрованной копии.
- **Разделение заметницы:** пароль основного приложения не открывает её данные.
  Из основного режима доступно лишь первичное создание. Смена пароля — из заметницы
  с прежним паролем. Совпадение паролей запрещено. Неверный/пустой пароль не открывает
  данные, задержка повторного входа сохраняется между запусками.
- **Экспорт:** экспорт чатов включает новые серверы/прокси/очередь; отдельная
  заметница в него не включается и не заменяется при восстановлении учётной записи.
- **Совместимость установки:** итоговый APK подписан тем же отладочным сертификатом,
  что и ранее выданная версия. Подпись проверена, обновление установлено без удаления.
  Закрытый signing key не включён в исходники.

## Изменённые компоненты

| Компонент | Изменение |
|---|---|
| MainActivity | Единый вход, серверы, расположение карточек, очередь, заметница и её UI |
| Vault | Переиспользованная схема защиты для двух областей, миграция, транзакционные обновления, проверка пароля без открытия данных |
| ChatApi | SOCKS5, принудительное прямое соединение без прокси, запрет запросов после закрытия |
| AccountData | Миграция, валидация, группы чатов и сохранение серверной идентичности |
| MessageIndex / MessageLayout | Дедупликация, источники, собственные сообщения и стороны карточек |
| DeliveryQueue / SyncEngine | Устойчивая очередь, независимые серверы, повторы, reconnect и проверка подключения |
| ProxySettings / Socks5SocketFactory | Валидация и RFC 1928/1929 с авторизацией и удалённым DNS |
| NotebookData / PasswordRouter | Данные заметницы, раздельные пароли и ограничение попыток |
| Ресурсы / Manifest / Gradle | RU/EN, название/иконки, версия 1.1.0, прежний applicationId/API 24 |
| JVM и Android-тесты | Новые сценарии и сохранённые регрессионные проверки |

`Crypto.java` и параметры шифрования сообщений/резервной копии не изменены.

## Запущенные проверки

- `assembleDebug` — успешно.
- `assembleDebugAndroidTest` — успешно.
- `testDebugUnitTest` — **39 тестов, 0 ошибок**:
  CryptoTest 7, ChatApiTest 4, FeatureDataTest 15, Socks5Test 7, SyncEngineTest 6.
- `lintDebug` — **0 ошибок**. Три предупреждения: абсолютные LEFT/RIGHT, выбранные
  согласно требованию, и отсутствие monochrome в fallback-иконке API 26;
  для API 33+ предусмотрен отдельный ресурс с monochrome.
- `adb shell am instrument -w com.loner.encryptedchat.test/com.loner.encryptedchat.IsolatedTestRunner`
  на эмуляторе Android 15/API 35 arm64 — **11 тестов, 0 ошибок**:
  LegacyMigrationDeviceTest 1, NotebookDeviceTest 3, UiDeviceTest 3, VaultDeviceTest 4.
- Итого **50 автоматических тестов**.
- Проверено совпадение сертификата APK с предыдущей версией и установка обновления
  через `adb install -r` без удаления приложения. При обычном запуске после
  обновления проверены прежний пароль и сохранённый именованный ключ версии 1.0.

Тесты охватывают криптографические векторы и прежние функции, миграцию реального
зашифрованного файла версии 1, раздельные Keystore-области, смену паролей,
однополевой вход, заблокированный вход, сохранение заметки при уходе в фон,
переключатель и реальные gravity карточек, объединение вкладок, одинаковые тексты,
источники, очередь, отключённые серверы, быстрый успешный сервер при зависшем другом,
сверку неоднозначной отправки, поздний ошибочный ответ после подтверждения,
отмену сетевых задач удалённого чата, HTTP 401/reconnect, SOCKS5-auth, удалённый DNS,
таймаут и HTTPS/проверку hostname внутри SOCKS5-туннеля.

Исходные JUnit XML, Android-тестовый лог, Lint и проверка подписи вложены в
`validation/` архива проекта. Тесты UI используют отдельные каталоги/настройки;
тестовый код не включён в основной APK.

Физическое устройство API 24, реальная камера QR, сервер и SOCKS5 пользователя
не проверялись: адреса и учётные данные не предоставлены. Проверки сети выполнены
на контролируемых HTTP/HTTPS-серверах и SOCKS5-стендах. Для эксплуатации нужны
действительный HTTPS-сервер и учётная запись его администратора.

Протокол SOCKS5 сверялся с [RFC 1928](https://www.rfc-editor.org/info/rfc1928/)
и [RFC 1929](https://www.rfc-editor.org/info/rfc1929/).
